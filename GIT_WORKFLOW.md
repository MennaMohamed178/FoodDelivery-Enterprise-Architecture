
# Git Workflow

This file documents the Git commands used in the FoodDelivery project.

## Branch Management
- `git branch` - List available branches.
- `git checkout practical/git-workflow` - Switch to the practical branch.

## Saving Changes
- `git status` - Check the current working tree.
- `git add .` - Stage project changes.
- `git commit -m "message"` - Save changes in a new commit.

## Uploading Changes
- `git push my-github practical/git-workflow` - Push commits to GitHub.
- `git log --oneline` - View recent commits.
